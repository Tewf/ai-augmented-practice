# Frame: what the field calls a practice read as an algorithm

The repository reads each practice of a research workflow as an instance of a named problem, so that it can be compared with the best algorithm for that problem. No single field uses this name. Two nearby fields name most rows.

## The problem in one sentence

For each practice, find the problem class the field names, the best-known algorithm and its implementation, and measure the distance between them.

## Does the name match

- "Practice as algorithm" names the method, not a field. The nearest field name for the whole is sequential decision analytics.
- The name is kept. A rename would move the address for no gain, as the family's earlier records decided.
